The feedback layer for Tool- and TUI-tier commands that run for more than a moment or print more than a line. None of it needs a Bubble Tea program of your own.

## Color scheme and emoji

One theme, defined once (`theme.go` below), used by both the status-line helpers and the `slog` handler, so every line in a tool reads the same way.

| Level | Emoji | Label | Color (basic ANSI, follows the user's terminal palette) |
|---|---|---|---|
| debug | 🐛 | `debug:` | bright black (gray), shown only with `-v` |
| step | 🔹 | `step:` | cyan |
| info | 🔵 | `info:` | blue |
| success | ✅ | `ok:` | green |
| warning | 🟡 | `warn:` | yellow |
| error | ❌ | `error:` | red |

Only the emoji and the bold label carry the color; the message stays the terminal's default color.

### When color and emoji turn off

Decided per stream, never by hand-written `if` chains. `lipgloss.Fprint*` applies the color profile from `colorprofile.Detect`, which follows no-color.org and bixense.com/clicolors. Every row was verified by capturing real output on 2026-10-09:

| Situation | Color | Emoji | Looks like |
|---|---|---|---|
| Terminal | ✅ | ✅ | `🟡 warn: 2 assets have no checksum` (label yellow) |
| Terminal + `NO_COLOR=1` (any non-empty value) | ❌ (bold/faint kept) | ✅ | `🟡 warn: 2 assets…` (label bold) |
| `TERM=dumb` | ❌ | ❌ | `warn: 2 assets…` |
| Pipe or file (`tool 2> log.txt`, `\| grep`, CI logs) | ❌ | ❌ | `warn: 2 assets…` |
| Pipe + `CLICOLOR_FORCE=1` | ✅ | ✅ | the terminal look, for `\| less -R` |

- `NO_COLOR` is only about color (that's the spec), so emoji stay. To also drop emoji there, change `useEmoji` to return false when `os.Getenv("NO_COLOR") != ""`. Make that a deliberate choice, not a default.
- Plain mode is `label: message`, the classic Unix diagnostic shape (`gcc`, `git`), so `grep '^error:'` works on logs.
- Pick emoji that are double-width by default (🔵 ✅ 🟡 ❌ 🔹 🐛). Avoid `ℹ️` and `⚠️`: they're U+FE0F presentation variants, which some terminals draw one column wide, so they overlap the next character.
- Basic ANSI colors (`lipgloss.Blue`, `lipgloss.Yellow`…), not hex. The user's terminal theme picks the exact shade, and they stay readable on light and dark backgrounds. Use hex or 256-color values only for decoration such as the accent and table borders.

## One job per component

| Need | Use | Stream |
|---|---|---|
| A step, info, ok, warning or error line | `ui.Step/Info/OK/Warn/Error` (theme above) | stderr |
| Structured details (`key=value`) | `slog` via `newLogger`: `charm.land/log/v2` with the theme's level labels | stderr |
| Something is happening, duration unknown | `charm.land/huh/v2/spinner`: `.Title().Context(ctx).ActionWithErr(fn).WithOutput(stderr).Run()` | stderr |
| Something is happening, N of M | `ui.NewTally(title, n)`, then `Inc()` per finished item, then `Done()`. One line: spinner + `bubbles/v2/progress` bar + `n/total`. `ui.Progress` wraps it for sequential steps | stderr |
| Tabular **data** | `charm.land/lipgloss/v2/table` for a terminal, **TSV for a pipe** | stdout |
| Hierarchy (files, deps, plan) | `charm.land/lipgloss/v2/tree` with `tree.RoundedEnumerator` | stderr (or stdout if it is the data) |
| Next steps, a summary, a warning that must not be missed | Lip Gloss `RoundedBorder()` box, at most one per run | stderr |
| Markdown (long help, release notes) | `charm.land/glamour/v2` (v2.0.1). Not shown; add only when there is real Markdown | stdout |

## Rules

1. **Never branch on color yourself.** Style with Lip Gloss, print with `lipgloss.Fprint*`, and the stream's profile does the rest. Never print styled strings with `fmt.Fprint*`, because that bypasses downsampling and leaks ANSI into pipes.
2. **Animate only on a terminal outside CI.** Spinners and bars need `interactive`. Otherwise print a `step:` line, do the work, and print the `ok:` line. Never write `\r` or cursor codes into a log.
3. **Every spinner and bar ends in a status line:** `✅ ok: Fetched 3 releases`, or `❌ error: fetch releases: <err>` plus exit 1.
4. **Tables are data: TSV when stdout is not a terminal.** Box-drawing characters break `cut`, `awk` and `sort`. `--json` beats both. In the terminal table, **cap free-text cells** (issuer names, error reasons) at about 28–30 runes with a trailing `…`. One long value otherwise widens the table past the terminal and wraps every row. TSV and JSON keep the full value. Put the cause first in any error that lands in a cell (`404 Not Found (GET <url>)`, not `GET <url>: 404 Not Found`), so the capped cell still says why. The report asset's `truncate` and `status` do both.
5. **Don't use huh's accessible spinner as the non-TTY fallback.** As of huh v2.0.3 it still writes ANSI codes and leaves its line unterminated. Branch on `interactive` yourself (see `Spin`).
6. **Short work gets no spinner.** Under ~300 ms it only flickers.
7. **One accent color** (212, pink) for headers and the spinner. Semantic colors stay reserved for their meaning: yellow means warning everywhere, never "highlight".
8. **Every wait shows motion (the user's standing preference).** Anything that can take more than a moment on a terminal must have a *ticking* spinner, so it's obvious work is happening. A progress bar alone isn't enough: it freezes while items are in flight (the first network round-trip, a slow item). Use `Tally`, whose spinner ticks on its own goroutine, never a bar that redraws only on `Inc`. For unknown-length work, use `Spin`.

<!-- asset: ux/theme.go -->
```go
package main

import (
	"image/color"
	"io"
	"log/slog"
	"os"

	"charm.land/lipgloss/v2"
	charmlog "charm.land/log/v2"
	"github.com/charmbracelet/colorprofile"
)

// Level is the meaning of a line; the theme decides how it looks.
type Level int

const (
	LevelDebug Level = iota
	LevelStep
	LevelInfo
	LevelSuccess
	LevelWarn
	LevelError
)

type levelStyle struct {
	emoji string
	label string
	color color.Color
}

// theme is the one place the color scheme and emoji live. Basic ANSI colors
// (not hex) so the user's terminal palette decides the exact shade. Emoji are
// ones that are double-width by default; avoid ℹ️/⚠️ (U+FE0F variants), which
// some terminals draw one column wide and overlap the next character.
var theme = map[Level]levelStyle{
	LevelDebug:   {"🐛", "debug", lipgloss.BrightBlack},
	LevelStep:    {"🔹", "step", lipgloss.Cyan},
	LevelInfo:    {"🔵", "info", lipgloss.Blue},
	LevelSuccess: {"✅", "ok", lipgloss.Green},
	LevelWarn:    {"🟡", "warn", lipgloss.Yellow},
	LevelError:   {"❌", "error", lipgloss.Red},
}

// Output modes, decided once per stream:
//
//	terminal              emoji + colored label
//	terminal + NO_COLOR   emoji + bold label, no color (NO_COLOR is only about color)
//	pipe, file, TERM=dumb plain "label: message", no emoji, no ANSI (grep-friendly)
//
// CLICOLOR_FORCE=1 forces the terminal look into a pipe.
func useEmoji(w io.Writer) bool {
	return colorprofile.Detect(w, os.Environ()) != colorprofile.NoTTY
}

// prefix renders "💡 info:" (or "info:" without emoji). lipgloss.Fprint* strips
// or downsamples the color to fit the stream, so callers never branch on color.
func prefix(l Level, emoji bool) string {
	s := theme[l]
	label := lipgloss.NewStyle().Bold(true).Foreground(s.color).Render(s.label + ":")
	if emoji {
		return s.emoji + " " + label
	}
	return label
}

// newLogger returns a slog logger whose level labels use the same theme.
func newLogger(w io.Writer, verbose bool) *slog.Logger {
	level := charmlog.InfoLevel
	if verbose {
		level = charmlog.DebugLevel
	}
	l := charmlog.NewWithOptions(w, charmlog.Options{Level: level})
	styles := charmlog.DefaultStyles()
	emoji := useEmoji(w)
	for cl, tl := range map[charmlog.Level]Level{
		charmlog.DebugLevel: LevelDebug,
		charmlog.InfoLevel:  LevelInfo,
		charmlog.WarnLevel:  LevelWarn,
		charmlog.ErrorLevel: LevelError,
	} {
		styles.Levels[cl] = lipgloss.NewStyle().SetString(prefix(tl, emoji))
	}
	l.SetStyles(styles)
	return slog.New(l)
}
```

```go
package main

import (
	"context"
	"fmt"
	"io"
	"strings"
	"sync"
	"time"

	"charm.land/bubbles/v2/progress"
	"charm.land/huh/v2/spinner"
	"charm.land/lipgloss/v2"
)

// UI writes human-facing feedback to stderr using the theme in theme.go.
// Colors are downsampled by lipgloss.Fprint* (stripped for pipes, NO_COLOR,
// TERM=dumb); emoji only on a terminal; animations only on a terminal outside CI.
type UI struct {
	w           io.Writer
	interactive bool
	emoji       bool
}

func newUI(stderr io.Writer) *UI {
	return &UI{w: stderr, interactive: isTerminal(stderr), emoji: useEmoji(stderr)}
}

var faint = lipgloss.NewStyle().Faint(true)

func (u *UI) line(l Level, format string, a ...any) {
	lipgloss.Fprintln(u.w, prefix(l, u.emoji)+" "+fmt.Sprintf(format, a...))
}

func (u *UI) Step(format string, a ...any)  { u.line(LevelStep, format, a...) }
func (u *UI) Info(format string, a ...any)  { u.line(LevelInfo, format, a...) }
func (u *UI) OK(format string, a ...any)    { u.line(LevelSuccess, format, a...) }
func (u *UI) Warn(format string, a ...any)  { u.line(LevelWarn, format, a...) }
func (u *UI) Error(format string, a ...any) { u.line(LevelError, format, a...) }

// Spin runs action behind a spinner. Without a terminal it prints the title as a
// plain step line and runs the action, so logs and CI stay clean. (huh's own
// accessible mode still emits ANSI codes and no newline as of huh v2.0.3.)
func (u *UI) Spin(ctx context.Context, title string, action func(context.Context) error) error {
	if !u.interactive {
		u.Step("%s", title)
		return action(ctx)
	}
	return spinner.New().
		Title(title).
		Context(ctx).
		ActionWithErr(action).
		WithOutput(u.w).
		Run()
}

// Tally is one live progress line: spinner, title, bar, n/total. The spinner
// ticks on its own goroutine, so the line keeps moving while work is in flight
// even when no item has finished yet. Inc is safe from many goroutines (use it
// as the per-item callback of an errgroup fan-out). Without a terminal it draws
// nothing. Always call Done, which stops the spinner and erases the line.
type Tally struct {
	mu                 sync.Mutex
	u                  *UI
	title              string
	done, total, frame int
	bar                progress.Model
	stop               chan struct{}
	wg                 sync.WaitGroup
}

var spinStyle = lipgloss.NewStyle().Foreground(lipgloss.Color("212"))

func (u *UI) NewTally(title string, total int) *Tally {
	t := &Tally{u: u, title: title, total: total, bar: progress.New(progress.WithDefaultBlend(), progress.WithWidth(30))}
	if u.interactive {
		t.stop = make(chan struct{})
		t.wg.Add(1)
		go t.spin()
	}
	return t
}

func (t *Tally) spin() {
	defer t.wg.Done()
	tick := time.NewTicker(spinner.Dots.FPS)
	defer tick.Stop()
	for {
		select {
		case <-t.stop:
			return
		case <-tick.C:
			t.mu.Lock()
			t.frame++
			t.draw()
			t.mu.Unlock()
		}
	}
}

// Inc marks one item finished.
func (t *Tally) Inc() {
	t.mu.Lock()
	defer t.mu.Unlock()
	t.done++
	if t.u.interactive {
		t.draw()
	}
}

// draw redraws the line in place; call with t.mu held.
func (t *Tally) draw() {
	frame := spinner.Dots.Frames[t.frame%len(spinner.Dots.Frames)] // frames carry a trailing space
	lipgloss.Fprintf(t.u.w, "\r%s%s %s %d/%d", spinStyle.Render(frame), t.title,
		t.bar.ViewAs(float64(t.done)/float64(t.total)), t.done, t.total)
}

// Done stops the spinner and erases the line; print the outcome line after it.
func (t *Tally) Done() {
	if t.stop != nil {
		close(t.stop)
		t.wg.Wait()
		t.stop = nil
	}
	if t.u.interactive {
		fmt.Fprint(t.u.w, "\r\033[K")
	}
}

// Progress runs step for each of total items sequentially behind a Tally, then
// prints the ok line. Without a terminal only the ok line appears.
func (u *UI) Progress(ctx context.Context, title string, total int, step func(i int)) {
	t := u.NewTally(title, total)
	defer t.Done()
	for i := range total {
		if ctx.Err() != nil {
			return
		}
		step(i)
		t.Inc()
	}
	t.Done()
	u.OK("%s %d/%d", title, total, total)
}

// Box frames a short note, e.g. next steps at the end of a run.
func (u *UI) Box(title, body string) {
	box := lipgloss.NewStyle().
		Border(lipgloss.RoundedBorder()).
		BorderForeground(lipgloss.Color("240")).
		Padding(0, 1)
	heading := lipgloss.NewStyle().Bold(true).Render(title)
	lines := strings.Split(body, "\n")
	for i, l := range lines {
		lines[i] = faint.Render("$ ") + l
	}
	lipgloss.Fprintln(u.w, box.Render(heading+"\n"+strings.Join(lines, "\n")))
}
```

<!-- asset: ux/main.go -->
```go
// Command tour shows every polish component once: status lines, spinner,
// progress bar, table, tree, box, and a pretty slog handler.
package main

import (
	"context"
	"fmt"
	"io"
	"os"
	"os/signal"
	"syscall"
	"time"

	"charm.land/lipgloss/v2"
	"charm.land/lipgloss/v2/table"
	"charm.land/lipgloss/v2/tree"
	"golang.org/x/term"
)

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	code := run(ctx, os.Stdout, os.Stderr)
	stop()
	os.Exit(code)
}

func run(ctx context.Context, stdout, stderr io.Writer) int {
	ui := newUI(stderr)
	log := newLogger(stderr, os.Getenv("VERBOSE") != "")

	ui.Step("Resolving config")
	ui.Info("Using profile %q", "default")
	log.Info("loaded config", "path", "~/.config/tour.toml", "profiles", 3)
	log.Debug("cache", "dir", "~/.cache/tour", "hit", true)

	var releases []release
	err := ui.Spin(ctx, "Fetching releases…", func(ctx context.Context) error {
		var err error
		releases, err = fetchReleases(ctx)
		return err
	})
	if err != nil {
		ui.Error("fetch releases: %v", err)
		return 1
	}
	ui.OK("Fetched %d releases", len(releases))

	ui.Progress(ctx, "Downloading", 20, func(int) { time.Sleep(40 * time.Millisecond) })
	ui.Warn("2 assets have no checksum")
	ui.Error("mirror eu-west unreachable, skipped")

	printReleases(stdout, releases)
	fmt.Fprintln(stderr)
	lipgloss.Fprintln(stderr, layoutTree())
	fmt.Fprintln(stderr)
	ui.Box("Next steps", "tour install v2.1.0\ntour verify --all")
	return 0
}

type release struct{ Tag, Date, Assets string }

func fetchReleases(ctx context.Context) ([]release, error) {
	select {
	case <-ctx.Done():
		return nil, ctx.Err()
	case <-time.After(1500 * time.Millisecond):
	}
	return []release{
		{"v2.1.0", "2026-10-08", "12"},
		{"v2.0.6", "2026-08-11", "12"},
		{"v2.0.0", "2026-02-24", "10"},
	}, nil
}

// printReleases is data, so it goes to stdout: a styled table for a human, TSV for a pipe.
func printReleases(w io.Writer, rs []release) {
	if !isTerminal(w) {
		for _, r := range rs {
			fmt.Fprintf(w, "%s\t%s\t%s\n", r.Tag, r.Date, r.Assets)
		}
		return
	}
	header := lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("212")).Padding(0, 1)
	cell := lipgloss.NewStyle().Padding(0, 1)
	t := table.New().
		Border(lipgloss.RoundedBorder()).
		BorderStyle(lipgloss.NewStyle().Foreground(lipgloss.Color("240"))).
		Headers("TAG", "DATE", "ASSETS").
		StyleFunc(func(row, _ int) lipgloss.Style {
			if row == table.HeaderRow {
				return header
			}
			return cell
		})
	for _, r := range rs {
		t.Row(r.Tag, r.Date, r.Assets)
	}
	lipgloss.Fprintln(w, t)
}

func layoutTree() *tree.Tree {
	return tree.Root(".").
		Child("main.go", "cli.go", tree.Root("internal").Child("fetch", "verify"), "testdata").
		Enumerator(tree.RoundedEnumerator).
		EnumeratorStyle(lipgloss.NewStyle().Foreground(lipgloss.Color("240")))
}

func isTerminal(w io.Writer) bool {
	f, ok := w.(*os.File)
	return ok && term.IsTerminal(int(f.Fd())) && os.Getenv("CI") == ""
}
```

Notes:

- `Tally` uses `bubbles/progress` as a plain renderer (`ViewAs`) and huh's `spinner.Dots` frames, with no Bubble Tea program. The spinner goroutine and `Inc` share one mutex, so many workers can call `Inc` concurrently (verified under `-race`). Its `WithDefaultBlend()` gradient degrades on its own on 16-color terminals.
- huh's spinner picks its title color from the detected terminal background. In a terminal that doesn't answer the background query, it assumes a light background.
- Kong's `--help` is plain and uncolored. That's fine; don't hand-roll a colored help printer. (`fang` colors help only for Cobra.)
